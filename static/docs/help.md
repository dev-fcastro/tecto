# Documentación de Tecto

Tecto es un sistema de generación de documentos corporativos basado en LaTeX.

## Flujo de Trabajo
1. **Selección:** Elige una plantilla desde el Workspace.
2. **Edición:** Llena los campos dinámicos en el formulario de la izquierda.
3. **Compilación:** Haz clic en "Compilar" para generar el PDF real.
4. **Descarga:** Una vez listo, descarga tu documento PDF profesional.

## Gestión de Plantillas
Puedes crear nuevas plantillas definiendo campos y código LaTeX. Tecto se encarga de la sustitución automática de variables.

## Assets
Sube logos e imágenes para personalizar tus documentos.
